# CPU Scheduling Simulator

This project implements CPU Scheduling Algorithms:

1. First Come First Serve (FCFS)
2. Shortest Job First (SJF)
3. Round Robin (RR)
4. Shortest Remaining Time First (SRTF)

## Input
- Process ID
- Arrival Time
- Burst Time

## Output
- Waiting Time
- Turnaround Time
- Gantt Chart

## Algorithms
- FCFS
- SJF
- Round Robin
- SRTF (Preemptive SJF)
